# primigenum/.github

Ficheros de salud de comunidad para todos los repositorios de la organización:

- `SECURITY.md` — cómo reportar vulnerabilidades.
- `PULL_REQUEST_TEMPLATE.md` — plantilla de PR.
- `ISSUE_TEMPLATE/` — plantillas de issue (bug y feature).

Los repos pueden sobrescribirlos con sus propios ficheros.
